# Санитары — визуальная новелла и база знаний

Сайт-пересказ игр по НРИ «Санитары» (Kids on Bikes) с канала «Хроники Ходов».
Каждый эпизод читается как визуальная новелла: фоны, спрайты, реплики персонажей,
броски кубиков и ссылки на нужный момент записи на YouTube. Рядом — база знаний:
персонажи, локации, улики, словарь мира и поиск по репликам.

Сборка не нужна: это обычные HTML, CSS, JS и JSON. Работает на GitHub Pages бесплатно.

## Как выложить на GitHub (один раз)

1. Создайте на github.com новый репозиторий, например `sanitary`.
2. Нажмите **Add file → Upload files** и перетащите всё содержимое этой папки (не саму папку). Commit.
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`. Save.
4. Через минуту сайт будет по адресу `https://toster69.github.io/corpsman/`.
5. Откройте `data/config.json` и впишите `"repo": "Toster69/corpsman"` — в редакторе появится кнопка «Править на GitHub».

## Как добавлять спрайты и фоны

- Спрайты кладите в `assets/sprites/`, например `assets/sprites/emily/default.png`.
  Лучше PNG с прозрачным фоном, обрезанный по фигуре. Белый контур «вырезки» сайт рисует сам.
- Фоны — в `assets/bg/`, например `assets/bg/gazebo.jpg` (16:9, от 1600×900).
- Пропишите пути в `data/characters.json` и `data/locations.json`:

```json
"sprites": { "default": "assets/sprites/emily/default.png", "scared": "assets/sprites/emily/scared.png" }
```
```json
{ "id": "gazebo", "name": "Беседка", "bg": "assets/bg/gazebo.jpg", ... }
```

Пока путь пустой (или файл не найден), рисуется нарисованная заглушка.
Эмоции (`default`, `scared`, `smile` …) — это просто ключи; заводите любые.

## Как править тексты

**Через встроенный редактор (удобно).** Откройте на сайте вкладку «Редактор».
Правки сразу видны у вас в браузере (оранжевая метка «черновики»). Чтобы их увидели все:
«Скачать JSON» → на GitHub откройте папку с этим файлом → *Add file → Upload files* → загрузите с тем же именем → Commit.
Или «Скопировать JSON» → «Править на GitHub» → выделить всё, вставить → Commit.

**Новый эпизод из субтитров.** Редактор → «+ Эпизод из .srt». Загрузите субтитры с записи —
получится черновик с таймкодами. Дальше назначайте, кто говорит, сокращайте, ставьте фоны.
Скачайте два файла: `data/episodes/epXXX.json` и `data/config.json`.

**Руками в JSON.** Строка эпизода — объект одного из видов:

| Что | Пример |
|---|---|
| Рассказчик | `{ "n": "Листва падает на дорожки." }` |
| Реплика | `{ "c": "emily", "say": "Эй, у вас всё хорошо?", "e": "worried" }` |
| Мысль | `{ "c": "emily", "think": "Это моё место." }` |
| Бросок | `{ "roll": { "who": "emily", "stat": "Шарм", "die": "d8", "dc": 8, "result": 4, "success": false, "tokens": "+1 Adversity Token", "note": "Узнать имя" } }` |

К любой строке можно добавить:
`"t": "00:12:34"` — момент в записи · `"bg": "studio"` — сменить фон ·
`"show": { "thompson": "right" }` / `"hide": ["thompson"]` — вывести или убрать персонажа ·
`"e": { "stranger": "smoke" }` — эмоция другого персонажа ·
`"fx": "negative" | "rain" | "shake" | "flicker" | "fade" | "none"` — эффекты ·
`"clue": "photo-1886"` — показать улику из списка `clues` эпизода.

Позиции: `farleft`, `left`, `center`, `right`, `farright`. Все `id` — латиницей и без дефисов.

## Посмотреть у себя на компьютере

Двойной щелчок по `index.html` не сработает (браузер не даёт читать JSON с диска).
В папке проекта выполните `python -m http.server` и откройте http://localhost:8000.

## Структура

```
index.html            точка входа
css/style.css         оформление
js/app.js             база знаний и плеер новеллы
js/editor.js          редактор
js/art.js             заглушки спрайтов и фонов
data/config.json      мир, словарь, порядок эпизодов
data/characters.json  персонажи
data/locations.json   локации
data/episodes/*.json  эпизоды
assets/sprites, assets/bg  ваши картинки
```
