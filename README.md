# Corpsman · Санитары — визуальная новелла и база знаний

Сайт-пересказ игр по НРИ «Санитары» (Kids on Bikes) с канала «Хроники Ходов».
Сборка не нужна: HTML, CSS, JS и JSON. Работает на GitHub Pages.

Сайт: https://toster69.github.io/corpsman/

## Как обновлять

```
git add .
git commit -m "Что изменилось"
git push
```

## Картинки

| Что | Куда класть | Где прописать |
|---|---|---|
| Спрайты | `assets/sprites/<id>/default.png` | `data/characters.json` → `sprites` |
| Кадр моргания (необязательно) | `assets/sprites/<id>/default_blink.png` | `sprites` → `"default_blink"` |
| Фоны 16:9 | `assets/bg/<имя>.jpg` | `data/locations.json` → `bg` |
| Логотип, баннер | `assets/brand/` | `data/config.json` → `logo`, `banner` |

Имена файлов — латиницей, маленькими буквами, без пробелов.
Пока путь пустой, рисуется заглушка в стиле Corpsman.

Моргание: для эмоции `scared` положите кадр с закрытыми глазами и пропишите `"scared_blink"`.
Нет кадра — персонаж просто «дышит» без моргания.

Персонажа, на которого не действует эффект негатива (как Незнакомка), отметьте `"immune": true`.

## Размеры в новелле

Всё настраивается в `data/config.json` → `novel`. Числа — проценты от высоты экрана новеллы, так что на любом мониторе пропорции одинаковые.

| Параметр | Сейчас | Что делает |
|---|---|---|
| `spriteHeight` | 118 | Высота спрайта. Больше 100 — фигура не помещается целиком и обрезается снизу окном текста, как в Persona |
| `spriteBottom` | -22 | Сдвиг низа спрайта. Минус — ниже края экрана. Меньше число → персонаж ниже |
| `boxHeight` | 30 | Минимальная высота окна текста |
| `textSize` | 4.6 | Размер текста (4.6 ≈ 33 px на экране высотой 720 px) |
| `nameSize` | 5.2 | Размер плашки с именем |
| `textFont` | Rubik | Шрифт реплик и мыслей (любой из Google Fonts, подключённый в index.html) |
| `narrationFont` | Rubik | Шрифт текста рассказчика |
| `textWeight` | 500 | Толщина: 400 обычный, 500 средний, 700 жирный |
| `mobileSpriteHeight`, `mobileSpriteBottom` | 78, 24 | То же для телефона |
| `mobileTextSize` | 18 | Размер текста на телефоне, в пикселях |

Подгонка отдельного персонажа — в `data/characters.json`:

```json
{ "id": "thompson", ..., "spriteScale": 1.08, "spriteY": -3 }
```

`spriteScale` — во сколько раз больше или меньше остальных (1.08 = на 8% выше), `spriteY` — сдвиг вверх (+) или вниз (−) в процентах высоты экрана.

### Спрайты

- PNG или WebP с прозрачным фоном, **холст 1437 × 1438** у всех персонажей одинаковый (так удобно хранить жесты).
- Персонаж в полный рост, ноги у нижнего края холста, как у Айзы.
- Белую обводку можно рисовать самим: сайт её не дублирует (`"outline": "auto"` в `novel`). Если у персонажа обводки нет и нужна сайтовая — поставьте ему `"outline": true`.
- Эмоции и жесты — отдельные файлы в папке персонажа, ключи придумываете сами:

```json
"sprites": {
  "default": "assets/sprites/aiza/01_AIZA_neutral_p1_v001.webp",
  "thinking": "assets/sprites/aiza/02_AIZA_thinking_p1_v001.webp",
  "power": "assets/sprites/aiza/06_AIZA_power_p1_v001.webp"
}
```

В эпизоде: `{ "c": "stranger", "say": "...", "e": "power" }`.

При холсте 1437 × 1438 хорошо смотрятся `spriteHeight: 150` и `spriteBottom: -62` — видно фигуру примерно до колен.

## Переходы

В `data/config.json` → `novel`:

| Параметр | Сейчас | Что делает |
|---|---|---|
| `sceneTransition` | halftone | Переход фона при смене сцены |
| `bgTransition` | fade | Переход, когда фон меняется внутри сцены (`"bg"` у строки) |
| `sceneIntro` | true | В начале сцены сначала только фон и название, потом выходят персонажи и текст |
| `sceneTitleMs` | 1900 | Сколько держится название сцены, в миллисекундах (клик пропускает) |

Виды переходов: `fade` — растворение, `halftone` — проявление растровыми точками, `wipe` — косая шторка, `slide` — сдвиг, `zoom` — наезд, `static` — помехи «переключения канала», `flash` — вспышка, `cut` — мгновенно.

Свой переход для одной сцены: `"transition": "wipe"` у сцены. Для одной строки со сменой фона: `"bgT": "zoom"`.

Спрайты анимируются сами: выходят из-за ближнего края экрана и уходят туда же, при смене эмоции старая картинка растворяется в новой с лёгким «подскоком», говорящий персонаж чуть подпрыгивает и выходит вперёд, остальные притемняются.

## Кассетный плеер

Внизу сайта — плеер-кассета, страница всех треков — вкладка «Музыка» (`#music`).
Треки описываются в `data/config.json` → `tracks`:

```json
{ "id": "mystery", "title": "Та, кого нельзя нарисовать", "src": "assets/audio/music/mystery.mp3", "hint": "Звучит, когда в беседке кто-то есть", "where": "Эпизод 00" }
```

- `"free": true` — трек открыт сразу (сейчас это `calm`).
- Остальные открываются, когда впервые звучат в новелле (тот же путь `src`, что у `"music"` в сцене). Зритель видит всплывашку «Новый трек».
- `hint` — подсказка у закрытого трека, `artist` — исполнитель (по умолчанию из `about.music`).
- Открытые треки хранятся в браузере зрителя (`corpsman:tracks`).

## Предупреждение, рамка, заставка

- Экран «Внимание» перед эпизодом: `config.json` → `warning.image` (`assets/brand/warning.webp`), `seconds` — сколько держать. Убрать: `"warning": null`.
- Стекло телевизора поверх новеллы: `config.json` → `tvGlass` (`assets/brand/tv-glass.webp`).
- Порядок при «Новой игре»: загрузка → предупреждение → заставка → «Ранее в…» → титульная карточка.

## Улики и кубики зрителя

Зритель сам бросает кубик за ключевые улики (3–5 на эпизод). Сюжет при этом идёт по канону: бросок решает только, попадёт ли улика в его «Дело».

Проверка — отдельная строка в эпизоде, ставится прямо перед моментом, где улика появляется:

```json
{ "check": { "clue": "sketches", "stat": "Шарм", "die": "d8", "dc": 8, "goal": "Удержать в памяти её лицо и перенести на бумагу" } }
```

У самой улики в `clues` добавьте `"partial"` — обрывок, который зритель получит при провале:

```json
{ "id": "sketches", "name": "Скетчи-фоторобот", "text": "Полное описание…", "partial": "На странице остались отдельные штрихи…" }
```

Правила для зрителя: выпал максимум — кубик «взрывается» и бросается ещё раз. Провал даёт +1 жетон невзгод, жетоны можно тратить, чтобы добрать недостающее. Найденные улики сохраняются между прохождениями.

Строки `"roll"` (что выбросил игрок на записи) в новелле больше не показываются — они остаются только в журнале на странице эпизода.

## Бонус за раскрытое дело

Открывается, когда все улики эпизода найдены броском. Если зритель выключил в ⚙ «Бросать кубики самому», улики он получает автоматически, но бонус не откроется.

```json
"bonus": {
  "title": "Из архива «Санитаров»",
  "text": "Материалы из прошлых версий…",
  "images": [ "assets/bonus/ep000/art01.webp", { "src": "assets/bonus/ep000/art02.webp", "caption": "Санитары, 2014" } ],
  "note": "Комментарий ведущего (необязательно)",
  "scene": { "title": "Глазами Айзы", "bg": "gazebo", "stage": { "stranger": "center" }, "lines": [ { "n": "…" } ] }
}
```

Страница бонуса: `#bonus-ep000`. Секретная сцена (`scene`) пишется так же, как обычная.

## Эпизоды без записи

Если у эпизода нет поля `video`, таймкоды и ссылки на запись не показываются. Пометка `"badge": "Эксклюзив"` и строка `"tagline"` выводятся на карточке и стартовом экране.

## Звук и музыка

Фоновая музыка сайта: `assets/audio/music/site.mp3` (`config.json` → `siteMusic`, громкость `volume` от 0 до 1). Играет на страницах базы знаний, затихает в новелле. Кнопка «Музыка» в шапке включает и выключает её, выбор запоминается.

Быстрый старт: положите 4 трека в `assets/audio/music/` с именами `calm.mp3`, `mystery.mp3`, `tension.mp3`, `ending.mp3` — эпизод 1 уже на них настроен (см. README.txt в этой папке).

Файлы — в `assets/audio/music/` и `assets/audio/sfx/` (mp3 или ogg).
Звук включается после первого клика зрителя, так устроены браузеры.

- Музыка сцены: `"music": "assets/audio/music/park.mp3"` у сцены. Сменить посреди сцены — то же поле у строки. Остановить — `"music": "none"`. Музыка тянется в следующие сцены, пока её не сменят.
- Звук на строке: `"sfx": "assets/audio/sfx/bell.mp3"`.
- Общие звуки в `data/config.json` → `sounds`: `roll` (бросок), `clue` (улика), `static` (переключение канала; если пусто — синтезированный шум).
- Музыка титров: `config.json` → `music.ending` или `"endMusic"` у эпизода.

## Заставка

`data/config.json` → `introVideo`:

```json
"introVideo": { "youtube": "ID_ролика", "video": "", "seconds": 20 }
```

- `youtube` — ID ролика (часть ссылки после `v=` или после `youtu.be/`).
- или `video` — путь к MP4 в репозитории, например `assets/video/intro.mp4` (так переход плавнее).
- Для одного эпизода можно задать свой `"introVideo"` прямо в его JSON или выключить: `"introVideo": null`.

Зритель может отключить заставку в настройках плеера (⚙).

## «Ранее в Corpsman»

Перед эпизодом показываются строки прошлого эпизода с пометкой `"recap": true`.
В эпизоде 1 такие строки уже отмечены — они появятся перед эпизодом 2.
Вместо этого можно написать свой пересказ в новом эпизоде:

```json
"previously": [
  { "c": "stranger", "text": "Твой собственный страх.", "bg": "negative" },
  { "text": "Эмили очнулась у лавочки в четыре утра.", "bg": "dawn" }
]
```

## Финал эпизода

Строится сам: «Конец эпизода» → «В ролях» (игроки из `players`, ведущий, NPC) → «Итоги» → тизер → ссылки.
Тизер задаётся в эпизоде:

```json
"teaser": { "title": "В следующем эпизоде", "bg": "manor", "lines": [ { "c": "thompson", "text": "..." }, { "text": "..." } ] }
```

## Строки эпизода

| Что | Пример |
|---|---|
| Рассказчик | `{ "n": "Листва падает на дорожки." }` |
| Реплика | `{ "c": "emily", "say": "Эй, у вас всё хорошо?", "e": "worried" }` |
| Мысль | `{ "c": "emily", "think": "Это моё место." }` |
| Бросок | `{ "roll": { "who": "emily", "stat": "Шарм", "die": "d8", "dc": 8, "result": 4, "success": false } }` |

Бросок не показывается отдельным кадром: он появляется тихой пометкой у следующей строки (зритель может её выключить).

Дополнительно у любой строки:
`"t": "00:12:34"` — момент в записи · `"bg": "studio"` — сменить фон ·
`"show": { "thompson": "right" }` / `"hide": ["thompson"]` · `"e": { "stranger": "smoke" }` ·
`"clue": "photo-1886"` · `"recap": true` · `"music"` · `"sfx"`.

Позиции: `farleft`, `left`, `center`, `right`, `farright` или число в процентах.

## Эффекты (`"fx"`)

Держатся до конца сцены (или до `"none"`): `negative` — негатив, `rain` — дождь, `vhs` — VHS-плёнка, `film` — зерно плёнки, `mirror` — присутствие зеркального человека.
Разовые: `glitch`, `flash`, `shake`, `flicker`, `fade`.

## Управление в новелле

| Действие | Мышь / кнопка | Клавиатура |
|---|---|---|
| Дальше | клик, колесо вниз, «Вперёд ▶» | → , пробел, Enter, PageDown |
| Назад (перечитать) | колесо вверх, «◀ Назад» | ← , PageUp |
| Перемотка | «Перемотка ▸▸» (клик — остановить) | удерживать Ctrl |
| Скрыть текст | «Скрыть» (клик — вернуть) | H |
| История реплик | «Лог» | L |
| Выйти | ✕ | Esc |
